# 随构 · 技术难点分析与降维策略

> 结论先行：**难点不在"画出来"，在"算得对"。** 装配语义+规则耦合占真实工程量约60%；自由编辑画布可绕开；钻孔显示是收尾活。

## 难度排序

### 第1难：装配语义引擎（拼接）★★★★★
- **长度推导**：横梁下料长 = 总宽 − 2×立柱截面 − 连接件偏移（每种连接偏移不同）。**下料错1mm用户装不上，产品即死**
- **约束传播**：改总尺寸→构件长度/孔位/配件数量全部联动，本质是参数依赖图(DAG)
- **槽口朝向**：旋转自由度决定面板/走线/配件可行性
- **组合爆炸**：连接×系列×朝向×端面处理，靠Golden用例池覆盖

> [!important] 关键降维决策（Vention验证过）
> 不做通用CAD约束求解器（6自由度mating，数年工程量）。利用型材系统天然离散化：槽口位置固定、连接件类型有限 → 装配 = **类型化接口的吸附/匹配**。难度从CAD级降到复杂业务逻辑级。

### 第2难：规则-几何耦合 ★★★★
- 连接决策→孔位特征→下料长度→BOM→价格，链条必须确定性、可重放
- 难在规则体系不打架：冲突仲裁逻辑（承重要30系列 vs 预算要20系列）
- 呼应 [[07-软件缺陷改进方案]]：规则即代码+Golden单测

### 第3难：AI意图层稳定性 ★★★
- 追问策略（何时问/问什么/几轮不烦）、抽取一致性、隐含常识补全（"放鱼缸"→推承重）
- 有界但需大量调教；30条真实需求测试集为此服务

### 第4难：自由编辑画布 ★★★★（但可绕开）
- 自由拖拽/吸附/框选/撤销重做 = 人力黑洞，无巧劲全苦工
- **AI-first最大架构红利**：Phase 0/1 只做"生成→参数面板微调→重新生成"，画布=查看器（旋转/缩放/点击构件/高亮孔位），Three.js两周
- 自由编辑推迟Phase 2甚至不做——生成+微调足够好则用户不需要拖拽

### 第5难：钻孔显示 ★★（看着难其实简单）
- 视觉：实例化圆柱/贴片标记+点击看参数，半天活；真布尔开孔Phase 2用CSG按需算
- 真难的是"孔位从哪来"=第1/2难的事

### 第6-7：导出与性能 ★
- 清单/BOM=模板活；DXF/STEP导出Phase 2用OpenCascade系
- 型材天然适合instancing，几百构件轻松

## 工程量分配建议

| 模块 | 占比 | 说明 |
|---|---|---|
| 装配语义引擎+规则耦合 | ~60% | 项目成败所在，最强的人投这里 |
| AI意图层 | ~20% | 提示词+追问策略+测试集调教 |
| 查看器+UI | ~15% | 成熟生态，苦工少 |
| 清单/输出 | ~5% | 模板活 |

## 行业参照

- **Vention.io**：类型化接点吸附装配的成功先例（重点研究其交互）
- **SolidWorks/Fusion mating**：通用约束求解=我们明确不做的反面参照
- **OpenCascade**：Phase 2 导出/布尔运算备选内核
- 嘉立创FA设计器：自由编辑路线的工作量参照（我们绕开的那条路）
