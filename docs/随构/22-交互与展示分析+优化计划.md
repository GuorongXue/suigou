## 一、当前交互模型

### 1.1 布局结构

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：品牌 | 状态标签 | 构件数/重量/价格 | 新方案 | 导出×3     │
├──────────┬──────────────────────────────┬────────────────────┤
│ 左栏 340px│         3D 查看器             │   右栏 340px        │
│          │                              │                    │
│ AI 对话  │    [外观|结构|图纸]           │   结构校验          │
│ 自然语言  │                              │   切割清单          │
│ 输入框   │      ┌──────────┐           │   板材清单          │
│          │      │          │           │   价格明细          │
│ ───────  │      │   3D     │           │   加工清单          │
│ 手动参数  │      │   模型   │           │   装配步骤          │
│ 滑杆×N   │      │          │           │                    │
│ 下拉×N   │      └──────────┘           │                    │
│ 勾选×N   │                              │                    │
│          │  选中构件详情卡(右上)          │                    │
├──────────┴──────────────────────────────┴────────────────────┤
│ 底栏：开发者诊断（Golden 用例状态）                             │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 用户主流程

```
用户输入自然语言 → AI 抽取参数 → 生成 3D 方案 → 查看/微调 → 导出制造文件
     ↑                                                                    │
     └──────────────── 修改参数/对话 ──────────────────────────────────────┘
```

## 二、交互问题清单（按严重度排序）

### P0 阻断性问题

| # | 问题 | 影响 | 根因 |
|---|---|---|---|
| 1 | **左栏参数区无分组/无层级** | 用户面对 20+ 控件无从下手 | 所有参数平铺，无视觉分组 |
| 2 | **AI 对话与手动参数割裂** | 用户不知道改参数后 AI 是否还理解 | 对话在顶部，参数在中部，无关联提示 |
| 3 | **参数变更无即时反馈** | 改滑杆后不知道方案何时更新 | 无 loading 状态、无变更高亮 |
| 4 | **选中构件编辑无约束** | 输入非法长度直接报错或静默失败 | 无输入校验、无合理范围提示 |

### P1 体验问题

| # | 问题 | 影响 |
|---|---|---|
| 5 | **右栏纯展示无交互** | 切割清单/板材清单不可点击、不可展开详情 |
| 6 | **视图模式切换无过渡** | appearance→structure→drawing 切换生硬，无动画 |
| 7 | **导出按钮始终灰显** | 用户不知道为什么不能导出，无引导修复 |
| 8 | **无撤销/重做** | 误操作无法恢复 |
| 9 | **结构校验信息密度低** | 只看颜色+文字，不知道问题构件在哪 |
| 10 | **装配步骤折叠过深** | 默认折叠，用户可能不知道有这功能 |

### P2 增强项

| # | 问题 |
|---|---|
| 11 | 无方案对比（A/B） |
| 12 | 无预设模板（一键"我要电脑桌"） |
| 13 | 无快捷键 |
| 14 | 无深色模式 |
| 15 | 无多语言 |

## 三、展示问题清单

### 3.1 3D 查看器

| # | 问题 | 严重度 |
|---|---|---|
| V1 | 构件选中态仅靠颜色（蓝），无轮廓加粗/半透明遮罩 | P1 |

## 四、竞品对标（嘉立创 FA）

| 维度 | 嘉立创 | 随构（当前） | 差距 |
|---|---|---|---|
| 输入方式 | 参数面板+预设模板 | 自然语言+手动参数 | 随构更自然，但缺模板 |
| 3D 交互 | 旋转/缩放/剖切/爆炸 | 旋转/缩放 | 缺剖切/爆炸 |
| 标注 | 常驻总尺寸+选中尺寸 | 仅选中尺寸 | 缺常驻标注 |
| 清单 | 可展开/可搜/可排序 | 静态表格 | 缺交互 |
| 导出 | 一键 DXF/BOM/装配图 | CSV TXT | 格式单一 |
| 协作 | 分享链接/评论 | 无 | 超出 Phase 0 |
| 响应速度 | <1s 生成 | 实时生成 | 随构更快 |

## 五、优化计划（分 4 批）

### 第一批：信息架构重组（P0，核心体验）

**目标**：让用户 30 秒内找到想要的控件

1. **左栏分组折叠**
   - "快速参数"（展开）：宽/高/深 + 场景 + 载荷
   - "板材与封板"（折叠）：顶/隔/底/背/侧/门
   - "结构与外观"（折叠）：截面/连接件/颜色/斜撑/中柱
   - "高级"（折叠）：LED/振动/移动性
2. **AI 对话置顶固定** + 参数区在下方独立滚动
3. **参数变更即时反馈**：滑杆释放时显示 loading spinner + 3D 模型淡入
4. **导出按钮引导**：灰显时 hover 显示原因 + "去修复"链接

### 第二批：3D 查看器增强（P1，展示质量）

1. **选中态强化**：轮廓加粗（OutlinePass）+ 非选中件半透明
2. **结构校验定位**：点击校验条目 → 相机飞向问题构件 + 高亮
3. **常驻总尺寸标注**：外轮廓三向尺寸链（W/D/H）
4. **视图切换动画**：相机插值动画（300ms ease）

### 第三批：清单交互化（P1，制造实用性）

1. **切割清单可点击** → 选中对应构件 + 显示单件加工图
2. **板材清单可展开** → 显示板件排布图（套裁可视化）
3. **BOM 汇总表**：连接件/紧固件分表，含单价×数量
4. **装配步骤增强**：每步配 3D 爆炸视图缩略图

### 第四批：高级功能（P2，差异化）

1. **预设模板**：电脑桌/置物架/工具柜 一键加载
2. **方案对比**：A/B 并排查看
3. **快捷键**：R-旋转 / F-聚焦 / 1/2/3-视图模式
4. **深色模式**

## 六、实施优先级建议

```
第一批（信息架构）→ 第二批（3D 增强）→ 第三批（清单交互）→ 第四批（高级功能）
     ↓                    ↓                    ↓
  立即做（1-2 天）     第 2 天              第 3 天
```

**第一批是最高优先级**：当前左栏 20+ 控件平铺是最大体验瓶颈，用户打开页面后不知道从哪开始。

---

## 七、技术风险提示

1. **OutlinePass（选中轮廓）**：需要 postprocessing 管线，增加 GPU 开销
2. **相机动画**：需要状态管理（当前无），可能与 OrbitControls 冲突
3. **分组折叠状态**：需要新增 state，增加 App.tsx 复杂度
4. **常驻尺寸标注**：需要计算外溢包围盒，大模型可能有性能问题
