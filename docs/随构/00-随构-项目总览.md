## AI驱动 · 精细化主轴（2026-08-04 战略定调）

> [!important] 定调
> 放弃"避开嘉立创找缝隙"的防守框架。正面做得更好：**它给会设计的人一个工具，我们给每个人一个懂制造的工程师。** 不考虑其供应链体系，唯一主轴 = AI驱动做到极致。

### 全链路精细化六环节

1. **意图理解**：工程师式对话而非填表。追问按优先级：结构安全(承重/跨度) → 成本(系列/材质) → 外观。提问策略本身是知识库的一部分
2. **生成式设计**：输出方案空间(2-3个有真实取舍的方案)而非单一答案；每个选型决策可展开成人话解释"为什么"
3. **知识内化**：G=19-T+2 这类公式自动执行，用户无感。知识库三层：公开工艺数据 → 结构力学(惯性矩/挠度) → 经验规则(老师傅直觉，最难爬最值钱)
4. **校验仿真**：每方案自动跑挠度/连接强度/稳定性，输出安全系数——"AI方案带结构计算书"做成信任壁垒(嘉立创不敢做)
5. **交付物生成**：装配顺序/爆炸图/分步安装图是生成时的零成本副产品(嘉立创要人工画)
6. **数据飞轮**：方案生成 → 用户修正 → 成交 → 使用反馈 → 知识库进化。我们的知识库是活的，它的工艺页是死的

### 战略一句话

不做"更全的设计器"，不做"缝隙市场"——**做设计能力本身的自动化。它卖工具和零件，我们交付结果。**
