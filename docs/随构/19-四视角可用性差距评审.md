# 随构 · 四视角可用性差距评审

> [!info] 文档定位
> 用户实测后提出"引擎距可用标准差距还非常大"，本文从**用户/平台/下料/工人**四个视角系统盘点差距，输出优先级路线。架构基线见 [[17-项目架构设计]]，问题上游见 [[16-产品体验与结构能力评测]]。

## 〇、用户实测观察（触发本评审）

| 观察 | 核实结论 |
|---|---|
| 没有侧板 | 引擎+UI 实际已有左/右侧板（参数下拉+四角固定 Mount），但**发现性差**：折在下拉里、意图层"侧板"一词映射不稳、外观无透明材质区分 |
| 没有盖板/抽屉/把手/电灯 | 属实，产品词汇表缺口（见一.1） |
| 结构模式看不到斜撑/面板连接点 | 代码有小蓝球（仅结构模式），但**无编号、无悬停说明、太小易被面板遮挡** |
| 面板价格没算 | 属实：BOM 中"待询价" |
| 面板尺寸没有 | UI 右栏清单只列型材；尺寸只在导出 CSV 里 |
| 两侧岛台不能收缩 | 属实，无折叠交互 |

## 一、用户视角（下单的人）——"这不是我要的柜子"

1. **产品词汇表太窄**：真实需求是"带门的工具柜""带抽屉的工作台"。缺：底板/盖板、门板（合页+磁吸）、抽屉（滑轨+抽面）、把手、锁、围网、灯条/走线、键盘托、脚垫。嘉立创配件库数百种，随构只有脚轮。意图层听到"抽屉"只能进 unsupported——用户直接流失。
2. **总价不可信 = 无法决策**：总价≈型材价；面板/连接件/紧固件/脚轮全无价格。
3. **侧板存在但被埋没**：参数被折叠、无透明材质渲染区分（玻璃/亚克力）。
4. **交互硬伤**：侧栏不可折叠（3D 区被挤）、无 undo/redo、无多方案保存对比、改参数无影响提示。

## 二、平台视角（做生意的人）——"接不了单"

1. **报价闭环断裂**：缺 fasteners/panels/accessories 价格库（17号架构 8.1 规划的三个目录缺失）+ 加工费（打孔/攻牙按孔计价，孔数已数出但没乘单价）+ 运费估算。
2. **SKU 库太薄**：3 截面 + 4 连接件；平台起步至少 20/40 系列全 + 常用配件。
3. **订单产物不完整**：只有两张 CSV。需要图纸 PDF（标题栏/版本）、STEP、装配说明书、正式报价单。
4. **无版本/追溯**：无 revision、导出物无知识库版本戳（架构文档十二）。

## 三、下料视角（切割报价的人）——"没法排产"

1. **无套裁/利用率**：6m 原料切法、锯口补偿（嘉立创锯口约 5mm）、余料统计全缺，切割清单只有净长。
2. **面板加工完全缺失（制造断链）**：t-nut 固定意味着面板四角要打孔，但 machining 只覆盖型材；面板无下料图、无孔位——照现清单做出来的板装不上。
3. **UI 清单不含板材**：板材尺寸只在导出 CSV。

## 四、工人视角（装配的人）——"图看不懂，孔不会打"

1. **无单件加工图**：需要每件号一张图（长度+孔位尺寸线+加工面视图）。现在只有 3D 球标和"Φ7@340"文字。图纸模式的下一个真刚需。
2. **无装配说明**：无装配顺序、每步用件、工具规格、扭矩；无爆炸图。
3. **连接点无语义**：小蓝球无编号/悬停说明（哪个 Mount、什么螺丝），易被面板遮挡。
4. **镜像件无方向防呆**：件号分开了，图上无方向标记。
