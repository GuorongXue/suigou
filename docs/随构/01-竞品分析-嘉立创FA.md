# 竞品分析：嘉立创FA铝型材定制站

## 网站定位

铝型材"设计-选型-加工-报价-下单"一体化平台。把传统"发图纸给业务员人工报价"改造成"在线3D搭建 + 标准工艺规则引擎 + 实时报价 + 直接下单"的工业电商工具。

## 商业模式

- 型材按米卖 + 配件卖货 + 加工服务加价（攻牙/沉孔/斜切等）
- 目标人群：DIY用户、工装夹具工程师、设备集成从业者、小型制造企业
- 业务闭环：设计稿 → 选型 → 加工 → 规则校验计价 → 购物车 → 交付

## 关键工艺参数（我们知识库的现成教材）

- 材料：6063-T5 铝合金
- 下料公差：L≤1000mm ±0.3mm；L>1000mm ±0.5mm；壁厚参照 GB/T 5237.1-2017 高精级
- 加工工艺枚举：型材端面攻牙、沉头孔、扳手孔、锚式连接件通孔、口哨连接件盲孔、型材斜切（标准45°，非标30°~150°）
- 攻牙规则示例：国标15系列→M3(孔2.5/深8mm)；欧标2020D→M5(孔4.2/深12mm)；欧标30/国标30→M6(孔5.0/深15mm)；国标4040→M10(孔8.8/深24mm)
- 孔公差：通孔H7级、孔位位置度±0.2mm、深度±0.2mm、螺纹精度6H级
- 连接件决策关联加工：锚式连接件通孔孔位 G=19-T+2（T为槽口厚壁）→ 说明连接方式选择直接驱动加工参数
- 表面处理：本色/黑色喷砂氧化、喷砂电泳、银白氧化、白色烤漆、原木色(烤漆+转印)
- 价格感受：欧标2020 约15.4元/米，2040 约27.2元/米，2080 约50.3元/米

## 做得好的点

1. **规则引擎驱动报价**（最难复刻）：加工规则全部固化成系统规则，实时出价，壁垒是制造知识的结构化
2. **两条成交通道并联**：在线设计器（DIY用户）+ 上传3D图纸报价（工程师），两类用户都接住
3. **工艺参数页做成技术文档**：能力边界完全公开，降低售前咨询和售后争议
4. **设计稿工作台+开源**：设计稿成为用户资产，可fork别人的稿子降低启动成本
5. **供应链对齐体验**：2天发货 + 实时库存展示，后端能力转化为前台信任

## 弱点（= 我们的机会）

1. **"零门槛"是伪命题**：仍需懂连接件选型、加工细节联动（G=19-T+2这种公式）、欧标国标匹配、槽口朝向——真正服务的是"本来就懂型材、只是懒得跑线下"的人
2. **可扩展性小**：自动化闭环建立在"一切都是标准件+标准工艺"上，规则全人工录入且与平台耦合，扩品类边际成本不降
3. **只适合正交"方盒子"结构**：斜撑、异形、复杂受力就退回人工估价
4. **无结构/力学校验**：只做几何拼装，不管承重稳定性，DIY口碑隐患
5. **非标是断点**：客单价最高的非标订单体验最差（回到人工流程）
6. **多站点割裂**：xc.jlcfa.com 与 www.jlcfa.com 混跳，登录态/购物车不透明
7. **导购弱**：工艺表格专业但新手读不懂，缺"我想做个鱼缸架"式的场景化引导
8. **社区薄**：开源社区跳到 jlc-jdgf.com，内容少，无创作者激励
9. **B端能力弱**：无BOM导出、批量询价、对公结算、图纸版本管理

## 结论

嘉立创验证了市场真实存在且付费意愿成立。它的所有弱点指向同一根源：**专业知识留在用户侧、规则引擎与标准件池耦合**。AI原生的"意图驱动设计"正好打在这个软肋上，且它的组织与架构惯性使其难以快速掉头，窗口期估计12-24个月。

## 设计器交互拆解 2026-08-04（来源：用户提供的评测视频截图×3）

### 观察到的交互

1. **角码添加**：原子操作（点一下=选件+定位+配套加工一次完成），toast"添加连接件成功"；橙色箭头=有效放置点；角码朝向自动对齐，无手动旋转
2. **拖动横梁**：四方向实时间距标注（440/410/523/493mm）；上下文工具条（复制/删除/旋转/更多）；**长度=输入框改值（569mm），非拖端点** → 参数化构件而非自由几何
3. **透视(X-ray)模式**：框架半透明露出腔体内的内置连接件螺栓；流程=选件→点目标型材→自动定位+自动打孔（"它会自动帮你"）
4. **紫/蓝半透明块**：槽位占用标记——型材每个面的槽道被离散化为可占用区间

### 逆推装配数据模型

```
型材实例
 ├─ 参数：系列/截面/长度(参数化)/位置/朝向
 ├─ 每面 → 槽道 → 离散化占用区间[起,终]
 └─ 加工特征列表（孔位，由连接件反向生成）

连接件实例
 ├─ 类型（角码/内置/锚式…）
 ├─ 绑定：2根型材+各自槽道+位置参数
 └─ 派生：占用区间+加工特征+配套螺栓螺母BOM
```

**验证了 [[08-技术难点分析与降维策略]] 的"类型化接口吸附"假设**：无通用约束求解；连接件=绑定槽道的参数化对象；孔位/BOM=连接件派生物。随构生成引擎可直接采用此模型（它靠用户点，我们靠AI决策）。

### 对随构查看器的启示

1. **X-ray模式必做**（内置连接件/孔位展示的刚需，非炫技）
2. **间距标注优于绝对坐标**：参数微调界面用"到顶部距离"类语义参数，贴合用户心智
3. **连接件操作原子化**：选件+定位+打孔+配件BOM一次完成，不暴露中间步骤

##### 自动化水平实况（修正认知）
- **"一键生成连接件"已存在**：全局默认件类型（默认角码，可改），所有接点批量套用
- 修正表述：它="批量执行"，我们="逐接点智能决策"（按承重/美观/成本逐点选型）
- 新手弹窗证实：紫色块=可点击连接锚点（类型化接口点实锤）；螺钉放置/端面中心孔悬停→自动生成加工特征（攻丝）——**加工特征=连接动作的派生物**，与逆推数据模型一致

##### 报错行为（它的短板=我们的空间）
- "当前面无法装配连接件"：面级合法性判定存在，但**只报错不解释不给建议**
- 我方AI差异化：解释原因+给替代方案（"槽位被占，建议相邻面或端面连接件"）

##### 型材库数据结构（知识库Schema现成答案）
- 分类树：15/20/30/40/45/50/62系列+特殊型材；每系列标注**槽宽**（欧标30槽8、国标30槽6等），欧标国标并列

- → 型材选型表Schema：`系列/标准/槽宽/壁厚/米重/单价/截面变体`（米重→重量成本估算，壁厚→强度，槽宽→配件兼容）

#### 补充拆解 2026-08-04 第六批（红色冲突态截图 + 浏览器活体探测）

##### 约束传播实验结果（最重要竞争情报）
- 改梁长900mm → 梁**穿出框架变红**、关联立柱变红，**其余构件纹丝不动**
- 结论：**嘉立创没有约束传播**！参数化只到单构件长度；构件间无依赖图；碰撞只检测标红不修复
- "整体尺寸"大概率仅是显示标注非全局驱动
- → 约束传播（[[08-技术难点分析与降维策略]] 第1难）它没做；AI全量重新生成天然自洽 = **硬代差机会**

##### 截面JSON Schema（TXCK-3030，语义化接口模型）
```
{ name,
  face0: { vertex[4], coreHoles[1], refHoleIndex },   // 端面：轮廓顶点+中心孔(攻丝用)
  sideFaces[4]: { startPoint, endPoint, normal, slots } }  // 四个侧面，每面带槽定义
```
→ 运行时模型不是完整DXF几何，而是**简化语义模型：端面轮廓+中心孔+侧面槽接口**。DXF管显示/制造，JSON管装配语义——"类型化接口"实锤到字段级

##### 连接件JSON Schema（EDLA-M8-L40）
```
{ size{W,H,D}, anchorPoint, offset,
  faces[2]: { isNormalPositive, adsorbFaceType, profileFaceType, faceIndex },  // 吸附面定义
  holesInfo[2]: { model, type, diameter, depth, startFaceIndex, isDirectionPositive, position, profileType },  // 所需加工孔
  locationFaces: { adsorb:2, orientation:1 } }
```
→ **连接件 = 吸附面声明 + 加工孔派生清单**，与逆推模型完全吻合。随构知识库的连接件Schema可直接参照此结构设计
