## 1. 四层收纳柜（工具收纳车）✅ 2026-08-14

**产品形态**：铝型材框架 + 周转箱抽屉 + 洞洞板侧板 + 木板顶面 + 福马轮，垂直塔式收纳柜。

### 实测尺寸链（图上标注，verified）

| 项目 | 数值 | 备注 |
|---|---|---|
| 铝型材框架高度 | 740mm（四层）/ 575mm（三层） | 不含福马轮 70mm，其他层数以此类推 |
| 铝型材框架深度 | 405mm | 侧面（洞洞板面）方向 |
| 木板顶面尺寸 | 366 × 405mm | 厚 15mm，覆盖式顶板 |
| 单层抽屉节距 | 165mm | = 轨道 + 底托 + 周转箱 |
| 周转箱+底托高度 | 155mm | 抽屉本体，与节距差 10mm 为间隙 |
| 福马轮高度 | 70mm | 带刹车调平脚轮，整体总高 = 框架 + 70 |

### 反推出的结构规律

1. **层数↔高度是线性公式**：框架高 ≈ 顶板结构区 + 层数 × 165mm。四层 740 ≈ 4×165=660 + 80（顶部区+底部余量）；三层 575 ≈ 3×165=495 + 80。**抽屉类物件的高度应由"层数×节距+固定余量"推导，不是自由参数**。
2. **抽屉 = 周转箱 + 底托 + 抽屉轨道**，轨道直接固定在立柱侧槽（图见轨道螺钉打入型材槽）。这是标准化抽屉方案：不做木抽屉，用标准周转箱（低成本、模块化）。
3. **洞洞板做侧板**（不是背板）——侧面挂工具（磁性工具条/挂钩/收纳盒），标注"宜家开孔"制式。侧板兼收纳功能面。
4. **顶板略小于框架**（366 < 405 深度方向对比），木板 15mm 覆盖式。
5. **脚轮用福马轮**（调平+移动二合一），不是普通丝杆脚轮；高度 70mm 计入总高。
6. **正面无门无面板**：抽屉即正面。

## 2. 安装工艺（板材固定 + 角部连接谱系）✅ 2026-08-14

**来源**：创盈铝业科普图（抖音），逐项带板厚/配件/优缺点标注——这是板材接口规则的权威修正依据。

### 板材固定方式全谱系（按板厚分档）

| 方式 | 板厚 | 配件 | 优点 | 缺点 |
|---|---|---|---|---|
| 内嵌（槽内嵌板） | 6mm | 无 | 隐形 | 板厚受限、安装有难度 |
| 面板角槽 | 5-6mm | 面板角槽、顶丝 | 兼做连接型材与承托层板 | 支撑面小、拓展性受限 |
| 挤压角码 | ≥10mm | 角码、内六角螺栓、螺母、自攻螺丝 | 安装方便、强度高 | 成本高、需额外工具、不可平嵌 |
| 层板固定件（L型外露） | ≥10mm | 固定件、内六角螺栓、螺母、自攻螺丝 | 安装方便、强度高 | 截面外露、自攻螺丝需额外工具 |
| 层板固定件（平嵌型） | 12mm | 固定件、自攻螺丝 | 安装方便、强度高、平嵌、隐形 | 自攻螺丝需额外工具 |
| 层板托 | 12mm | 层板托（仅一件） | 平嵌、隐形、受力面大、可后装 | 成本高 |

### 角部连接件谱系（三向 90° 角）

压铸角码（+铝合金端盖）/ 三维连接件（外贴L板×3）/ 槽内连接件+面板角槽+连接板 / 内置连接件（隐藏圆销）/ 三通端面连接件（立方三孔）——同一个角至少 5 种连接方案，按强度/隐藏性/成本权衡。

### 槽用螺母三分法（预装属性是装配顺序约束）

| 螺母 | 预装 | 含义 |
|---|---|---|
| T型螺母 | 否 | 事后可入槽——装配顺序自由 |
| 滑块螺母 | 是 | 必须在封端前滑入——装配顺序约束 |
| 弹珠螺母 | 是 | 预装+弹珠定位 |

### 反推出的结构规律

1. **抽屉是最高频功能件**（7 例中 5 例有抽屉）：形态统一为"木箱体 + 金属侧滑轨 + 木面板"，滑轨直接固定在立柱/横梁槽上。抽屉面板可带型材边框（案例4）或纯木面板（案例5/6/7）。
2. **洞洞板侧板再次出现**（案例6，与四层收纳柜一致）——洞洞板 position=side 是真实高频形态，非 back。
3. **顶板三种做法**：覆盖式（木板盖框，案例4）/ 平嵌式（板与型材面齐平，案例5/7）/ 凹嵌式（板低于框沿，案例6）。当前引擎只有覆盖式。
4. **调平脚垫与脚轮同样高频**：案例3/5/7 用调平脚垫（不可移动但适应地面不平），当前引擎只有"fixed（无附件）/caster"两态，缺"调平脚垫"档。
5. **家具级五金**：拉手（弓形/嵌入式）、合页门、光轴作围栏/拉手——光轴是结构性配件不只是导轨。
6. **黑色氧化型材**（案例3）：颜色是真实选项，当前引擎无外观维度。
7. **人体尺度产品存在**（椅子）：坐高约 400mm、承重人体动载，超当前范围红线，保持诚实降级。

### 尺寸链验证（引擎公式的实证）

1. **宽 670 = 630梁 + 2×20柱** ✓ 与引擎"梁长=总宽−2×柱宽"公式完全一致（2020系列）
2. **深 400 = 360梁 + 2×20柱** ✓
3. **层间距 = 周转箱高 + ~2mm**：左视图分格 150×3 + 220×1 ↔ 周转箱 148×3 + 230×1 ✓ 抽屉节距公式实证
4. **中柱 775 = 810 − 35**：内部立柱比外柱短（顶部让位）
5. **总高 815 = 810立柱 + 5**（顶部板沿）

### 关键工艺发现

1. **"洞洞板"实为自打孔海洋板**：4mm 海洋板按宜家制式自打孔（孔距50/边距10/孔径5）——洞洞板可以是板材+打孔加工派生，不必是独立SKU
2. **2020 系列主连接件是内置角槽**（×30），不是角码——小型材用内置连接，外露角码仅辅助（垂直角码固定外挂面板）
3. **立柱端面攻 M6 丝装福马轮**（不是 M8）——2020 系列芯孔攻 M6
4. **层板托固定平嵌层板**（18mm 海洋板）——与安装工艺谱系一致
5. **导轨用 M4×10 半圆头螺丝+垫片**入槽固定
6. **两列不对称布局**：425 抽屉列 + 185 工具列——真实产品有内部分区（中柱+中梁），不是均匀网格
