# 随构 · 出图与导出规划（延伸思考）

> 触发：M2 查看器做三视图模式时，用户提出后期要考虑图纸导出、加工图纸等细节问题。此文档把出图相关的架构决策提前锁定，避免后期返工。

## 0. 核心架构决策（现在就生效）

**所有导出物一律从 FrameModel 语义数据生成，绝不从 3D 网格反推。**

现在的 `Member`（角色/长度/位置/朝向）、`Joint`（接点/连接件）、`MachiningOp`（孔型/规格/位置）就是全部图纸的单一数据源。这意味着：

- 引擎数据结构里的位置字段必须保持**工程语义**（如孔位置=距端面距离，而不只是世界坐标）——`MachiningOp` 后续补 `offsetFromEnd` 字段
- 查看器只是语义数据的一种"渲染器"；SVG 图纸、DXF、PDF 是另外几种"渲染器"，同源不同面
- 这是嘉立创同款思想（它的设计器数据模型驱动下料/加工/BOM），也是为什么我们坚持不做自由网格编辑

## 1. 导出物清单（按优先级）

| 优先级 | 导出物 | 内容 | 技术路线 | 里程碑 |
|---|---|---|---|---|
| P0 | **切割清单 CSV** | 截面/长度/数量/公差档位 | 前端直接生成下载 | M3 顺手做 |
| P0 | **BOM 清单 CSV** | 型材+连接件SKU+配件（螺母/螺栓）+数量+估价 | 同上，joints×connector.bom 聚合 | M3 顺手做 |
| P1 | **方案图纸 PDF**（A4） | 等轴测总图+三视图+整体尺寸+清单表+**免责三要素标题栏** | 语义数据→自绘 SVG（正交投影自己算，不依赖Three.js截图）→ pdf | M5 前后 |
| P1 | **单件加工图** | 每种唯一构件一张小图：长度、孔位（距端面尺寸链）、孔规格（Φ/攻丝深）、数量 | 同 SVG 路线，模板化 | M5 前后 |
| P2 | **DXF 下料/加工文件** | 加工厂直接可用（LINE/CIRCLE/TEXT 实体） | DXF 是文本格式，手写 writer 即可（无重依赖） | Phase 1 |
| P2 | **装配步骤说明** | joints 数据→装配顺序（先框后梁、内置件先插）→图文步骤 | asm-002 装配顺序规则的正向应用 | Phase 1 |
| P3 | **GLTF 分享模型** | 网页/微信可预览的 3D 模型 | Three.js GLTFExporter 现成 | Phase 1 |
| P3 | **STEP 专业格式** | 对接 SolidWorks/Fusion 用户 | 需 opencascade.js（重）或服务端转换，**不承诺** | Phase 2+ |

## 2. 细节性问题清单（现在记下，届时不漏）

### 图纸规范
- [ ] 标题栏：方案号、日期、比例、版本、**免责三要素**（估算依据/非专业认证/高风险场景提示，07文档）
- [ ] 三视图布局：主视+俯视+侧视+等轴测角，第一角法（国标 GB/T 17451）
- [ ] 尺寸标注链：总尺寸→分段尺寸→孔位尺寸，避免封闭尺寸链（基准面标注）
- [ ] 公差标注：按 tolerance.yaml 场景档位自动标（普通±0.5/工作台±0.3/门框±0.2/精密±0.1）
- [ ] 字体：图纸内中文需嵌入字体（PDF），DXF 用 SHX 兼容字体名

### 加工图细节
- [ ] 孔位基准：一律从**同一端面**起标（装配基准=加工基准），避免累积误差
- [ ] 对称构件标注"两端对称"省图；镜像件（左右柱）注意区分或注明"可互换"
- [ ] 攻丝标注：M8×20 需注孔径底孔 Φ6.8（工艺页数据已有）
- [ ] 沉头孔标注：Φ9 沉 Φ14×8.5 + 沉头方向（哪个面进刀）
- [ ] 同长度不同加工的构件必须拆成不同件号（当前 cutList 按长度聚合会合并它们——**M3 时件号系统要按"长度+加工特征"聚合**）⚠ 这是当前数据结构的已知坑

### 下单对接
- [ ] 嘉立创下单格式对齐：它的清单页字段（长度/数量/加工选项）截图已在竞品文档，导出格式照着做，用户可直接复制下单
- [ ] 配件归并：t-nut/bolt 按规格汇总，标注"建议多买10%备损"
- [ ] 价格时效：导出物注明"估价基于 YYYY-MM-DD 价格快照"

### 数据结构预留（M3 实施时落地）
- [ ] `Member` 加 `partNo`（件号：长度+加工特征哈希）
- [ ] `MachiningOp` 加 `offsetFromEnd`（距端面距离，工程语义）与 `memberId`（归属构件，当前只有 jointId）
- [ ] `FrameModel` 加 `meta`（方案号/生成时间/知识库版本/价格快照日期）——图纸标题栏数据源

## 3. 不做清单（防蔓延）

- 不做 CAD 级通用制图（图层管理/自定义标注样式）
- 不做 STEP 除非用户真实需求验证（重依赖）
- 不做动画装配指导（Phase 2 再评估）
