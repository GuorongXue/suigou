# 随构 · 项目全面审视与增长策略

> [!important] 决策记录（2026-08-04）
> **先做价值、后做变现。** 免费优先跑通产品与增长，商业化功能延后。两条边界：
> 1. 架构必须预留收费点（导出/高级校验/批量），避免日后加费墙重构
> 2. 账号体系与埋点第一天就要有——数据飞轮是唯一护城河

## 一、文档体系补充项（审视发现的空白）

- [ ] 增长与推广策略（本文档承载，见下）
- [ ] 合规三件套：ICP备案（提前2个月启动）/ 结构计算责任与免责声明 / 用户数据合规（个保法）
- [ ] 成本模型：单次生成LLM成本、免费限额、防滥用、相似需求缓存、小模型分流
- [ ] 北极星指标体系：周生成方案数 → 方案分享/导出率 → 方案落地率
- [ ] 冷启动内容：自产50个高质量场景方案（猫爬架/直播间/温室等），SEO素材+模板库起点
- [ ] 团队分工与节奏文档：双周迭代+月度里程碑（业余项目最大死因=不了了之）

## 二、优点

1. 差异化主轴清晰，对手路线图证实AI空窗（见 [[01-竞品分析-嘉立创FA]]）
2. 品类观入口词错位=蓝海流量（"猫爬架定制"vs"铝型材"，见 [[05-品类观与创意图谱]]）
3. Phase 0 纯软件、不碰供应链交易，验证成本低
4. 传播性内置：生成过程即营销素材，产品即内容
5. 先准备后开发的文档纪律已建立

## 三、缺点/薄弱点

1. **团队无机械行家**，知识库质量靠外部评审——最脆弱一环
2. 业余时间 vs 12-18个月窗口期，时间最稀缺
3. 免费期纯投入，无收入对冲LLM成本
4. 生成质量长尾：demo惊艳易、稳定可靠难，口碑死于早期翻车案例
5. "创意无限vs规则有限"张力：超纲需求的降级体验必须精心设计
> [!note] 2026-08-04 补充
> 缺点1/3/4/5及结构安全措辞风险已有细化工程方案，见 [[07-软件缺陷改进方案]]（含 Phase 0 适用子集划分）。

## 四、风险矩阵

| 风险 | 等级 | 应对 |
|---|---|---|
| 结构安全责任（塌/砸） | 高 | 免责声明+措辞降级（"估算参考"非"承诺"）+保守安全系数+高风险场景（水族/儿童）人工提示 |
| LLM成本失控 | 高 | 限额+缓存+小模型分流 |
| 知识库错误传播 | 高 | 行家评审门禁+反馈快速回收 |
| 嘉立创上线AI | 中 | 开发群预警已建；发生则拼垂直深度+混材品类 |
| 团队松散不了了之 | 中 | 分工节奏文档，双周迭代 |
| 备案/合规拖期 | 低 | 提前启动 |

> [!warning] 对既有表述的修正
> [[00-随构-项目总览]] 六环节中"校验仿真做成信任壁垒"保留，但对外措辞必须是"估算参考"而非"安全承诺"，责任设计先行。

## 五、免费期增长路径

内测（邀请制）→ 公测（免费+限额）→ 增长（内容驱动）→ 商业化（水到渠成）

- **内容即产品**：每个方案自带可分享页（3D交互+清单），分享即获客
- **短视频冷启动**："一句话生成猫爬架"过程录屏，投B站/小红书/抖音DIY与宠物垂类
- **社区借力**：嘉立创开发群（已在）、创客社区、宠物DIY小组
- **模板库自产**：50个方案兼做SEO与用户起点

## 六、北极星指标（免费期）

1. 周生成方案数（活跃）
2. 方案分享/导出率（价值认可）
3. 方案落地率——用户真按清单买料了（PMF信号，可用回访/晒单激励测量）
