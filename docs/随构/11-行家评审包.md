# 随构 · 机械行家评审包（可直接发给对方）

> 使用说明：预约 45-60 分钟（付费咨询更高效，市场价约 200-500 元/小时或一顿饭）。
> 先发"背景一页纸"，再按问题清单逐个问。**所有问题都设计成可勾选/可填空**，避免开放题。
> 记录规则：行家确认 → 条目升 verified；行家修正 → 按修正值入库；行家说"不一定/看情况" → 追问"取决于什么"，把条件记下来（那就是新规则）。

> 我在做一个工具：用户说"我要一个1米2宽的工作台，放得下50公斤的东西"，系统自动用铝型材（2020/3030/4040那种）生成结构方案、选连接件、出切割清单。

## 评审记录

### 第一部分：选型阈值 —— ✅ 已完成 2026-08-04

| # | 行家答案要点 |
|---|---|
| 1 | 2020跨600@30kg=勉强；**集中载荷有可见挠度，均布尚可**；不建议长期 |
| 2 | 2020长期极限：600mm@20kg / 800mm@10kg；定位轻型框架/护罩/电子设备 |
| 3 | 3030跨1200@80kg=勉强偏不建议；集中载荷挠度明显，建议4040或加中柱 |
| 4 | 3030闭眼边界：1000mm@50kg / 800mm@80kg（均布）；超出则计算而非凭经验 |
| 5 | 4040触发：跨度>1.2m/载荷>80kg/振动/**精度要求高**；核心优势是刚度非强度 |
| 6 | 立柱≠横梁：立柱校核Euler屈曲，横梁校核弯曲+挠度；**短柱可小一级，高柱不可降** |
| 7 | 人身安全场景：**安全系数≥2.0 且控制挠度**，不能只满足强度 |

**新发现的建模维度**（原Schema缺失）：① loadType 载荷分布(集中/均布)；② memberRole 构件角色(横梁/立柱)与屈曲校核；③ 刚度需求(need: precision)作为选型触发。
已同步至 [[10-知识库种子数据]] v0.2（sel-*升verified，val-003安全系数1.5→2.0，新增val-004立柱屈曲）。

### 第二部分：连接件强度排序 —— ✅ 已完成 2026-08-04
| # | 行家答案要点 |
|---|---|
| 8 | 抗弯强度排序：**端面攻丝 > 锚式 > 角码 > 内置**；端面攻丝=轴向预紧利用端面受力；内置的优势是美观不是承载（**修正了我方原排序：内置误标高于角码**） |
| 9 | 三条禁令：内置件不单独主承重（振动易松）；长横梁不靠单角码（双侧固定+闭合框架）；槽内摩擦不抗动载 |
| 10 | 斜撑量化：高>1000mm 或 高宽比>3:1 必须加；"晃不是型材不够强，是整体抗剪不足" |
| 11 | 脚轮必须区别对待：连接方式整体升一级+加斜撑/角板；动态冲击+扭转+疲劳 vs 静载 |

**新发现建模维度**：mobility(固定/脚轮)；loadRole(主承重/定位美观)；闭合框架设计原则。
已同步 [[10-知识库种子数据]]：连接件strengthClass全verified并修正、con-005脚轮规则、val-005~007新增。
