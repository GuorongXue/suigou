# 随构 · 品类观与创意图谱

> [!important] 品类观定调（2026-08-04）
> 跳出"横平竖直做支架做柜子"的局限。铝型材的本质是**标准化程度最高、最易获得的"可编程结构总线"**——T型槽是开放的物理接口协议，任何材料配上适配器都能挂上来。
>
> **产品 = 型材骨架 + 异质材料填充 + 接口适配器**

## 一、材料 × 创意空间

### 玻璃/亚克力（透明界面）
- 展示柜/手办柜（+LED槽内灯条，槽口天然是灯条散热槽）
- 3D打印机/CNC防护罩、无尘罩、鱼缸底滤柜
- 发光灯箱招牌（导光板+槽内LED）

### 木头（温感表面）
- 工业风书桌/餐桌（型材腿+实木台面）、原木层架
- 猫爬架主体、床架+木床板、玄关换鞋凳

### 绳子/绑带/织物（柔性张力）
- 猫爬架（麻绳缠柱+吊床）、攀爬网、儿童游戏架
- 露营天幕骨架、摄影柔光布框、投影幕布框
- 隔断屏风（帆布/窗帘轨道）、货架绑带固定

### 灯具/电气（功能注入）
- 直播间骨架（补光灯+背景板+声学棉+槽内走线）
- 植物生长架（生长灯+定时器+滴灌管卡槽）
- 电竞桌氛围灯、摄影棚灯轨；槽口=天然理线槽

### 网/板/膜（围合）
- 宠物围栏/鸡舍（铁网+围板）、阳台温室（阳光板）
- 工具墙（洞洞板嵌槽）、车间隔离网

### 混合创意示例
- 猫窗台活动区 = 型材+麻绳+木板+吊床布+亚克力观景泡泡
- 直播间 = 型材+灯具+吸音棉+背景布+显示器支架
- 阳台菜园 = 型材+种植箱+生长灯+滴灌+防鸟网

## 二、对随构的三个含义

1. **AI分解任务重定义**：不是"生成柜子"，而是"创意意图 → 骨架+填充+接口"的跨材料分解。嘉立创路线图加板材仍是"型材配件"思维，不是"混合材料产品"思维
2. **知识库新增"材料接口规则"层**：玻璃压条+安全余量、亚克力热胀间隙、木板T型螺母直固、绳索锚点件、LED灯条对槽宽……几十条规则覆盖主流材料，价值/成本比极高
3. **用户池直接拓宽**：宠物用品、直播电商、植物玩家、露营玩家——他们不知道"铝型材"这个词但有强定制需求。**搜"猫爬架定制"的人搜不到嘉立创，但能搜到我们**
